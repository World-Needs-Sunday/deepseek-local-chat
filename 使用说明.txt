DeepSeek 本地助手 —— 使用说明
================================

一、启动方法
  双击 deepseek-chat.html 即可在浏览器中打开使用，无需安装、无需登录。

二、功能说明
  1. 模型切换：顶部下拉框可在 V4.1 Flash（快，支持图片与联网搜索）和
     V4 Pro（更强，纯文本）之间切换。
  2. 思考强度：低 = 快速模式（关闭思考）；中 = 思考模式（推荐）；
     高 = 深度思考（更深入但更慢）。回复中的"思考过程"可点击展开/收起。
  3. 联网搜索：点顶部"联网"按钮开启。开启后 AI 会自己搜索网页并给出
     参考来源链接。注意：开启联网会自动切换到 Flash 模型。
  4. 图片上传：点击输入框左侧图片按钮，或直接 Ctrl+V 粘贴截图。
     图片会自动压缩后保存。注意：仅 Flash 模型支持图片，发送图片时会
     自动切换模型。
  5. 文件上传：点击输入框左侧按钮可选择常见文本/代码文件（txt、md、
     cpp、c、h、js、ts、py、java、json、csv、html、css、xml、sql、go 等，
     单文件 10MB 以内、每轮最多 4 个）。文件内容会随消息一起发给 AI，
     由 AI 阅读分析（每个文件最多取前 5 万字符）。聊天里的文件卡片点击
     可展开查看内容；文件内容会保存在本地记录中。
  6. 对话管理（左侧栏）：
     - 新建对话：创建全新对话
     - 删除对话：鼠标移到对话上点垃圾桶图标
     - 清空上下文：顶部垃圾桶图标（保留对话和 AI 要求，只删消息）
     - 撤回消息：鼠标移到消息上，点垃圾桶图标（撤回该条及之后的消息）
  7. AI 要求（长期记忆）：左下角"AI 要求与设置"。在这里写下的要求
     （例如"用中文回答""你是一名老师"等）会在每一轮对话中自动发给 AI，
     AI 会始终遵守。
  8. 数据导出：
     - 导出当前对话：顶部栏的下载图标按钮，导出为 Markdown 文件
       （包含思考过程与参考来源；图片以文字标注代替）。
     - 导出全部对话：左下角"AI 要求与设置"→"导出全部对话"按钮，
       导出为 JSON 文件（完整数据备份，不包含 API 密钥）。
     - 导入对话：左下角"AI 要求与设置"→"导入对话数据"按钮，选择之前
       导出的 JSON 文件即可恢复。导入会合并到现有对话列表，重复的
       对话自动跳过；也可用于换电脑后迁移聊天记录。

三、数据与密钥
  - 所有聊天记录、图片、设置都保存在本机浏览器的 localStorage 中，
    不会上传到任何第三方服务器（发送给 DeepSeek API 的对话内容除外）。
  - API 密钥需自行填写：打开应用后点左下角"AI 要求与设置"，填入你的
    DeepSeek API 密钥（platform.deepseek.com 获取）。密钥只保存在本机
    浏览器中，不会随网页公开。
  - 清除浏览器数据会导致聊天记录丢失，重要内容请自行备份。

四、常见问题
  - 提示 401：密钥无效，请检查设置中的 API 密钥。
  - 提示 402：DeepSeek 账户余额不足，请充值。
  - 提示 429：请求过于频繁，稍等再试。
  - 发送图片提示错误：图片过大（单张建议 30MB 以内），或未自动切换
    到 Flash 模型（刷新页面后重试）。

五、版本说明
  - deepseek-chat.html：轻量版，单文件零依赖，仅基础 Markdown 排版。
  - deepseek-chat-full.html：完整版，内置 KaTeX 数学公式渲染（行内
    $...$、块级 $$...$$）与 highlight.js 代码语法高亮。注意：完整版
    必须与 libs 文件夹放在同一目录下使用（zip 中已包含）。
  - 两个版本共用同一套本地聊天数据（同一浏览器下 localStorage 共享），
    切换使用不会丢失记录。
